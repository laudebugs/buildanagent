## The research question, answered before drafting

**Question.** When does an agent stop, who decides, and how does a program get a typed answer out of it?

**Answer, from the todo's sources only.** A loop stops in one of three ways. The model answers without asking for a tool, a stop condition the caller wrote holds, or a cap runs out ([SDK guide §3](../../../docs/guides/agent-sdk.md#3-the-loop-should-be-one-in-process-pure-function-capped-in-model-calls-that-ends-with-a-stop-reason)). The model decides the first; the caller decides the second; whoever wrote the SDK decides the third, unless the caller overrides it. The defaults range "from a footgun to no limit": one step for the AI SDK's `generateText`, twenty for its `ToolLoopAgent`, ten turns for OpenAI's `run()`, twenty-five graph super-steps for LangChain (thirteen model calls in our test), five hundred model calls for ADK, and none for Pi or the Claude Agent SDK (SDK guide §3; [feature table](../../../docs/comparison/feature-table.md), "Turn and spend caps"). They also count different units: steps, turns, super-steps and model calls.

Who decides is reported differently too. The SDK guide distinguishes a run's outcome from the model's own reason for ending a response. At the cap, the AI SDK returns normally, OpenAI throws `MaxTurnsExceededError`, LangChain throws `GraphRecursionError`, and the Claude Agent SDK yields a result whose subtype is `error_max_turns` before `query()` throws (feature table, "How a run ends"). The guide argues for a stop reason that a type system forces callers to read, over an exception or a silent return.

A program gets a typed answer by handing the SDK a schema. Every SDK offers a route as of November 2026, from the AI SDK's `Output.object` to Pi's final tool with `terminate: true` (feature table, "Structured output"). The SDK sends the schema with the request, then parses and checks the answer. What it does on a mismatch differs: the AI SDK rejects with `NoObjectGeneratedError`, OpenAI throws `ModelBehaviorError`, the Claude Agent SDK retries and then ends in `error_max_structured_output_retries`, and ADK's TypeScript port only logs the failure. A schema checks shape. It cannot check that the category is the right one, so the program still validates meaning itself.

**The one-line rule the chapter teaches.** Set your own cap in the unit your SDK counts, read the run's stop reason before you use its answer, and treat a schema as a check on shape, never on truth.

**Gap.** No source in the todo measures how often a real agent hits its default cap, or how far real tasks need to run, so the chapter's advice on sizing a cap is our judgement and claims no measured rate.
