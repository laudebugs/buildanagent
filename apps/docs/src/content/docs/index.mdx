Start with the SDK and the gateway. Install both with the `alpha` tag, which npm serves for every release until the first stable one:

<Tabs syncKey="package-manager">
  <TabItem label="pnpm">
  ```bash
  pnpm add @buildanagent/sdk@alpha @buildanagent/gateway@alpha zod
  ```
  </TabItem>
  <TabItem label="npm">
  ```bash
  npm install @buildanagent/sdk@alpha @buildanagent/gateway@alpha zod
  ```
  </TabItem>
  <TabItem label="yarn">
  ```bash
  yarn add @buildanagent/sdk@alpha @buildanagent/gateway@alpha zod
  ```
  </TabItem>
</Tabs>

## Start with a package

Pick the package you need. Every package starts with a guide.

<CardGrid>
  <LinkCard title="Gateway" description="Calls Anthropic or OpenAI-compatible models through one transcript and one stream format, with retries and a cost on every message. Read the install page." href="/start/install/" />

  <LinkCard title="SDK" description="Runs your agent's loop: it calls the model, runs the tools the model asks for and stops when the work is done. Test it offline with a scripted model. Build your first agent." href="/start/first-agent/" />

  <LinkCard title="Harness" description="Wraps the loop with a session log that survives a crash, a context policy, tools, permissions and a sandbox that holds no credentials. Run your first turns." href="/harness/quick-start/" />

  <LinkCard title="Agent safety" description="Gives every write a typed outcome, signs approvals and refuses a model call that could pass a run's USD cap. Make a write safe to repeat." href="/agent-safety/quick-start/" />

  <LinkCard title="Protocol" description="Describes the session entries, the client and server messages and the JSONL framing that carry them. Write your first request." href="/protocol/quick-start/" />

  <LinkCard title="CLI" description="Runs the harness in your terminal. Script one turn, chat with an agent that asks before risky calls, or search your stored sessions. Run your first command." href="/cli/quick-start/" />
</CardGrid>
