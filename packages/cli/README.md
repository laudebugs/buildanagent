# @buildanagent/cli

The command line runs the harness in a terminal. Nothing runs from it yet.

As of November 2026 the package is private and not on npm. It will depend on the harness and ship the `buildanagent` command. That command and its OpenTelemetry exporter arrive in later todos. The [harness plan](https://github.com/laudebugs/buildanagent/blob/main/docs/plans/build-harness.md) says what each package will hold and in which order.
