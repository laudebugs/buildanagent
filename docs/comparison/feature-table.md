# Agent SDK feature table: eight SDKs share one loop and differ most on safety defaults and state

*As of November 2026, for `@anthropic-ai/claude-agent-sdk@0.3.327`, `@earendil-works/pi-coding-agent@1.5.2`, `@openai/agents@0.21.0`, `ai@7.0.162`, `langchain@1.6.1`, `agents@0.33.0` (with `@cloudflare/think@0.23.0`), `@google/adk@2.5.0` and `@github/copilot-sdk@1.0.31`, all in TypeScript. Each cell links to the guide section, fact-check or [TypeScript gap report](typescript-gaps.md) section behind it. **(V)** means a runnable example in `verify/<sdk>/examples/` asserts the claim offline; **(D)** means the claim rests on the SDK's docs or package source; **—** means none of our sources covers it, and "Not covered in our reference" marks the same for the three SDKs added on 2026-11-18.*

The eight SDKs share one core idea: a model calls tools in a loop until a stop condition holds. They differ in who runs that loop and how much they decide for you. Claude's SDK and the GitHub Copilot SDK each spawn a separate runtime that owns the loop and ships a full coding toolset. Pi, by contrast, runs a full coding harness in your process and leaves every safety gate to you. The OpenAI Agents SDK runs an in-process loop with guardrails, handoffs and resumable approvals. At the thin end, the Vercel AI SDK keeps only the loop and an approval policy, and leaves state to you. LangChain.js puts its loop on a LangGraph graph and adds features as middleware. Cloudflare Agents makes each agent a Durable Object with its own SQLite database, and runs the Vercel AI SDK's loop inside it. Google ADK runs an `LlmAgent` through a `Runner` over a session, from a TypeScript port that trails its Python primary. Read the table by group: **Safety** and **State** separate the eight most sharply, while **Tools** and **Output** show how much they now share.

## Choose by the safety work you want to own

The table points to one decision: how much safety work you want to own. Pick the Claude Agent SDK if you want Claude Code's tools and permission system ready-made and can accept Claude-only models and a subprocess per session. Pick the GitHub Copilot SDK for the same kind of ready-made runtime from six languages, if you will strip its coding toolset with `availableTools` and write a permission handler for every session. Pick Pi if you want to own and read the whole harness, including its session tree and compaction, and will write the gates yourself. Pick the OpenAI Agents SDK if you need guardrails, handoffs and approvals that survive a restart, and will decide where traces go. Pick the Vercel AI SDK if you want the thinnest loop across providers and will bring your own state. Pick LangChain.js if you want the most ready-made middleware and durable threads, and will compile its examples against your release. Pick Cloudflare Agents if each agent should be a long-lived, addressable server whose state and pending approvals live in its own database, and you will deploy on Workers. Pick Google ADK if you want Gemini-first agents and graph workflows in Node.js, and will re-validate structured output and check each Python-only docs tag against the `.d.ts`. The [deep comparison](deep-comparison.md) builds the same triage agent on all eight and draws the lessons for our own stack.
