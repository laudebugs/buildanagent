# 0040. Connect each user's cloud with the provider's scoped, expiring delegation, and run every model call on the user's own key with no fallback

- **Status:** Accepted (owner, 2026-11-18)
- **Date:** 2026-11-18
- **Plan:** [build-agent-platform.md, PF6 and PF7](../plans/build-agent-platform.md#pf6-users-connect-their-own-clouds-with-scoped-expiring-credentials-accepted-adr-0040)

## Context

The platform deploys into accounts it does not own and must never pay for tenant model calls. Each target offers a delegation mechanism: Cloudflare OAuth clients and account API tokens, Vercel integrations with API scopes and project-scoped access tokens, and AWS cross-account roles with an external ID. The [agent-building platforms report](../research/deployment/agent-building-platforms.md#no-platform-deploys-a-built-agent-to-cloudflare-or-vercel-and-byo-key-usually-carries-a-markup) found that Vercel AI Gateway falls back to its own provider keys by default, while Cloudflare AI Gateway offers an opt-in `byok_only` setting that refuses to fall back.

## Decision

Each connection uses the provider's own delegation with the narrowest scope it offers: Cloudflare OAuth or an account API token from our template, a Vercel integration or a project-scoped token, and, in M9, an AWS role that requires a per-tenant `sts:ExternalId` generated by us. The platform stores these credentials encrypted under the tenant's key and uses them only in deploy adapters; they never enter a sandbox, the generator's context or generated code.

The platform holds no model key of its own for tenant work. The preferred path keeps the provider key in the user's Cloudflare AI Gateway with `byok_only` on, and the platform holds only a token with the gateway's `Run` permission. The fallback path stores the key encrypted under the tenant's key and adds it only at egress.

## Consequences

- Todos F7, F8 and F17 build the connections and deploy adapters; F9 builds BYOK and a test that a failed BYOK call ends in an error.
- Vercel AI Gateway is not used for tenant calls unless its fallback is turned off.
- A user without Cloudflare uses the encrypted-key path.
