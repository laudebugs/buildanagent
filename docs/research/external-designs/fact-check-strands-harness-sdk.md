# Fact-check log: Strands harness-sdk report

The Strands report holds up, and its recommendation stands. Seventeen of the 87 rows needed a correction, and three rest on inference. The largest correction is version skew. The draft described `main`, but its recommendation pins 0.4.0, which defaults to Claude Opus 5 rather than Opus 5.5 and lacks the AgentCore web-search tool and its AWS hard dependencies. Three corrections soften safety claims: the `smart` preset does not turn on tool-wide trust, the CLI's "never prompt" quote concerns project MCP files, and no source ranks Strands below every reference except Pi. Two more sharpen sessions and compaction, because compacted originals survive in a stash and the docs name an in-process guard beside the missing distributed lock. The rest fix our design's wording, an undercounted list of awaits, a release count, the earlier-claims count, and all six relative links, which pointed one level too shallow.
