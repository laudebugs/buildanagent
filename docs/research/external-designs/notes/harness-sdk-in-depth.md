## Repo facts: contents, licence, packages, versions, maintainers, status

### Takeaway
harness-sdk is not a separate "harness SDK" library: it is the Strands Agents **monorepo** (both core SDKs, the two harness packages, the `strands` CLI, an MCP docs server, the docs site, design docs). The "harness" is two thin 0.x packages, `strands-harness` (PyPI) and `@strands-agents/harness` (npm), both at 0.4.0 (2026-11-12), Apache-2.0, authored by AWS, Beta. The docs now brand the core SDK itself as the "Strands Harness SDK".

## What "harness" means here: components and API

### Takeaway
A "harness" is a **factory function** that assembles a fully configured core-SDK `Agent` with tuned defaults: Bedrock Claude Opus 5.5 with reasoning, a behavioural system prompt, eight built-in tools (shell, read/write/edit, web_fetch, web_search, programmatic_tool_caller, subagent), auto context management with offloading, prompt caching, file-backed snapshot sessions, file-backed long-term memory, Agent Skills, an environment-context plugin, optional interventions presets, background tasks, MCP loading and OTel exporter wiring. Almost every capability is implemented in the core SDK; harness code is about 4–5k lines per language of wiring plus a few tools.
