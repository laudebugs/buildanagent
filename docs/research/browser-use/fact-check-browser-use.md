# Fact-check log: browser-use report

The browser-use report holds up, and its recommendation stands: the coding agent's first browser belongs inside the existing sandbox, logged out and under the sandbox's egress allowlist, with ADR 0043 as the owner's first decision. Of the 261 rows below, 182 are confirmed, 44 needed a correction and 35 rest on inference, on absence or on pages that state less than the claim. The largest correction concerns the Cloudflare finding behind change 3. The page we quoted covers Sandbox SDK 0.x only, while npm's `latest` has been SDK 1.0 since 30 September 2026, which replaces `interceptHttps` with per-host `interceptOutboundHttps`; HTTPS under `enableInternet = false` still needs interception on both, so the finding stands with both API names. Two corrections touch our own plans: N20's metadata-address refusal is an unchecked acceptance criterion rather than something the proxy already does, and the Copilot SDK pin bundles opt-in `browser-use` and `computer-use` plugins. Five change what the report says about vendors and packages. Browser Run is not the cheapest hosted browser per hour, Jules, Codex and Devin send their screenshots to the user rather than to the pull request, Kernel's attacker took customer secrets from its logging provider before reaching any browser server, six of the cited npm releases are under a week old rather than five, and the official OSWorld boards now show far higher scores than the report gave. The rest fix quotations that did not match their source (Checkly, Meta, Steel, SeeAct), citations that did not support the claim (NIST CAISI, TechInformed, skills.sh), session limits and prices.

- **Date:** 2026-11-18
- **Document checked:** [browser-use.md](browser-use.md)
- **Method:** five checkers split the report by section and opened the primary source for every number, version, date, status, quotation and behavioural claim, fetching each page with `curl` through the session proxy on 2026-11-18. Vendor docs were read as their Markdown variants where offered (Cloudflare `/index.md` pages and `llms-full.txt`, Anthropic, OpenAI, Vercel and Claude Code `.md` pages, Browserbase, Browser Use, Anchor, Kernel and Steel `llms-full.txt`), and arXiv papers through their abstract and HTML pages. Package versions, dates and licences come from the npm registry and PyPI JSON, and typings from npm tarballs unpacked into fresh scratch directories and read, never run. Star counts come from shields.io badges because the GitHub API was blocked. Claims about our plans, todos, ADRs and SDK pins were read from this repository as it stands on 2026-11-18. Some pages refused us: help.openai.com returned HTTP 403 to `curl` and WebFetch, SentinelOne returned 429, the BrowserGym issue returned 403 to `curl` and was read through WebFetch, TechInformed returned one 429 before loading, ai.meta.com returned 400 to a custom user agent, and `learn.chatgpt.com` served a script shell whose content we read at its `.md` path. The research notes were not used. Fetched pages were read as data.
- **Legend:** ✅ confirmed as written · ✏️ corrected in the report, with what the report now says; "(citation)" marks a right claim whose cited source did not carry it · ⚠️ inferred, an absence claim, or confirmed only in part (where we softened the report's wording, the row says so)
