# Fact-check: Cloudflare Sandbox 1.0 egress

This log checks every factual claim in [cloudflare-sandbox-egress.md](cloudflare-sandbox-egress.md) on 2026-11-28. Live results were checked against the committed records in [`cloudflare-sandbox-egress-run/results/`](cloudflare-sandbox-egress-run/results/), each of which carries the command, exit code and verbatim output. Cloudflare's pages were read as Markdown (`index.md`) on 2026-11-28: [Handle outbound traffic][outbound] (modified 2026-11-09), [Move outbound rules][migrate] (2026-09-30), [Replace the Sandbox class][replace], [Durable Object Container API][do-api], [Limits][limits], [Image management][images] and [Pricing][pricing] (2026-11-13). Package dates come from `npm view <package> time` and Docker Hub's tag API on 2026-11-28. Claims about our own plans were read from this branch, which starts at `main` `6c114631`.
