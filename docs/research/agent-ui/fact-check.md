# Fact-check log: agent UI research synthesis

The synthesis holds up, and none of its conclusions changes. Eleven of the 81 rows needed a correction. The largest is the Copilot SDK event count, which falls from "about 170" to 154 `SessionEvent` types. The Magentic-UI gain also needed restating: it comes from a simulated user that held each task's human-written plan, so it does not isolate plan editing. Five more corrections fix labels: a last-updated date read as a start date, a "paid" layer that has a free plan, two `alpha` tags on the Claude browser SDK, and an "experimental" tag on Codex's `unix://` transport. The last four fix a paraphrase shown as a quotation, a dropped qualifier on Claude's legacy artifacts, and two citations to pages that lack the claim.
