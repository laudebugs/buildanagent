# Fact-check log: retrieval and long-term memory report

The retrieval and long-term memory report holds up, and its thesis stands: an agent should carry pointers, search with keywords first, and keep long-term memory as sourced records that it checks before trusting and forgets unless a check renews them. Of the 156 rows below, 122 are confirmed (✅), 19 needed a correction (✏️) and 15 rest on inference, on absence or on a secondary copy (⚠️). Each section was checked as soon as it was drafted, before the next was written, and the rows come in nine blocks, one per section, plus the re-checks of the writing review's fixes (rows 141–147) and of the owner's decisions applied (rows 148–156).

None of the corrections changes a finding. The pull request's review added three: the intro now gives MINJA's 98.2% as the rate of planting a record and 76.8% as the rate later queries obey it (row 4), and the Zep–Mem0 exchange is told in order, 84%, then 58.44%, then 75.14% (rows 96 and 97). Two fixed numbers or words that the source states differently: Self-Route's gaps are percentages, not points (row 14), and Chroma calls itself "open-source search infrastructure for AI", not a vector-database vendor (row 12). Two fixed counts in our own prose (rows 60 and 105, where all eight SDKs, not five, ship a search tool). Three replaced or added a citation (rows 27, 45 and 65), and one removed a placeholder link (row 127). The writing review's fixes (rows 141–147) cut one unchecked claim, that neither vendor SDK exposes the other's memory design, and repaired a causal link in the introduction.

The ⚠️ rows fall into three groups. Seven are our own synthesis, and the report labels each as ours: the carry rule, the write, recall and forget rules, the five-way grouping of forgetting mechanisms, the signals to buy and the BM25 size estimate (rows 26, 70, 79, 80, 90, 93 and 133). Six are absence claims or untested behaviour: no TTL in any SDK's typings, no newer statement of Anthropic's 200K rule, no Memory Bank TypeScript client, FTS5 in local workerd, the Copilot `storeMemory` path, and Memory Bank TTL read only in compiled JavaScript (rows 6, 19, 103, 117, 121 and 124). The other two rest on a secondary or an inferred source: the GDPR text came from a reproduction because EUR-Lex refused the fetch (row 89), and no regulator classifies agent-memory embeddings as personal data, so that conclusion is ours (row 58).

## Link check

Every relative link and anchor in the report, this log and the notes resolves. A script extracts each Markdown link target that is not `http(s):` or `mailto:`, resolves it against the file's folder, and matches each `#anchor` against GitHub-style slugs of the target's headings. On 2026-11-19 it checked 30 links in the report (23 distinct targets, 10 of them with anchors), 26 in this log and 23 in the notes, with no failures.
