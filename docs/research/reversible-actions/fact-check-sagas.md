# Fact-check log: sagas and compensation for agent actions

The sagas report holds up, and none of its conclusions changes. Nine of the 70 rows needed a correction. The largest settles a question the draft left open: MassTransit's source shows that routing slips compensate last-in, first-out and publish `RoutingSlipFaulted` only after every compensation succeeds, so the draft's call for a test before relying on the order is answered. The other corrections fix an overstatement in the introduction (MassTransit does distinguish the two failure outcomes), the Durable Functions retry bound, an unsupported claim about the Temporal .NET SDK, two paraphrases (Anthropic's "before each block runs" and A2A's terminal states), a field missing from the AD3 binding list, and the broken repo links. ## Corrections made

Each correction is in the report; the three notes keep their original text, except for the link fixes in correction 10, and their headers point here.

1. **Failure outcomes (row 15).** "Finally, every engine collapses 'failed and fully compensated' and 'failed with compensation incomplete' into one Failed status" became "every engine except MassTransit reports 'failed and compensated' and 'failed with compensation incomplete' as the same status".
2. **Temporal .NET (row 16).** "and the .NET SDK is in the same position" became "and the .NET sample takes the same hand-written approach".
3. **Durable Functions retries (row 32).** "Retries are opt-in per call through `TaskOptions` and, once set, 'continue indefinitely' unless a retry timeout is given" became "Retries are opt-in per call through `TaskOptions`, bounded by a maximum number of attempts; the separate retry timeout is unbounded by default".
4. **Dapr Java sample (row 40).** "appears to fall through … whether `complete` halts execution was not checked, so treat it as a possible docs bug" became "has no `return` after `ctx.complete` … the next `callActivity` throws `IllegalStateException` … so the sample is a docs bug", citing durabletask-java.

6. **Anthropic quotation (row 63).** "the check must happen before each batch 'because a batch can complete…'" became "the check must happen 'before each block runs, because a batch can complete…'".
7. **A2A terminal states (row 69).** "forbids changes after a terminal state" became "rejects further messages to a task in a terminal state".
8. **AD3 binding (row 66).** "request id, call id, tool, canonical input hash and policy version" became "request id, kind, call id, tool, canonical input hash and policy version".
