# Fact-check log: server rollback for agent tool calls

The report's design holds up, and none of its conclusions changes. Eleven of the 67 rows needed a correction, and two more rest on an absence of evidence. The largest correction settles Prisma 8's status. The report called it unresolved, but Prisma's own release-status page says Prisma 8 is still a release candidate.
