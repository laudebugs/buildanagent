# Fact-check log: agent connectors report

The report's recommendation stands, and its MCP 2026-07-28 facts held up: statelessness, POST-only Streamable HTTP, CIMD over a deprecated DCR, PKCE with S256, RFC 8707 resource indicators, RFC 9728 discovery and the 403 `insufficient_scope` step-up all match the spec, and every CVE and GHSA id is real and described correctly. The corrections cluster in three places. First, the platform survey overstated how rare ask-by-default is: Foundry defaults `require_approval` to `always` and the Responses API asks by default, so "only a minority … start write tools in an asking state" became a split between asking platforms and GitHub's cloud agent, which never asks. Second, several quotations were not verbatim, among them Composio's revocation sentence, GitHub's allowlist wording and Zapier's hosting statement, and Composio's 5,241 API keys were "potentially exposed", not exposed. Third, the draft missed `server/discover`, which every 2026-07-28 server MUST implement; it said a client must speak both eras "for at least a year", a timeline the spec never sets; and it said Cloudflare was the only one of our eight SDKs documenting a client OAuth flow, when Pi's mirrored docs describe one too. The check also found prior art the draft lacked: the AI SDK release we mirror ships `fingerprintTools` and `detectToolDrift` for rug-pull detection. Of 196 rows, 156 are confirmed, 33 corrected and 7 unverified or confirmed only in part. The direct reads resolved 11 of the draft's "(secondary)" and "(search summary)" markers; two stay (Salesforce's API Catalog and Asana), one was added (Salesforce's credentials), and AgentKit's registry claim stays unverified because openai.com refused the fetch.

- **Date:** 2026-11-18
- **Document checked:** [agent-connectors.md](agent-connectors.md)
- **Method:** I fetched every cited URL with `curl --max-time 30` on 2026-11-18 and read the claim's wording on the page, using each docs site's Markdown form (`.md` or `llms.txt`) where offered. Spec claims come from the `modelcontextprotocol.io/specification/2026-07-28/` pages; `/specification/latest` returned a 307 to that revision. Advisories come from `api.github.com/advisories` and each repository's security-advisories API, and CVE scores from the NVD API. Package versions and licences come from `https://registry.npmjs.org/<pkg>`, the GitHub licence API and the `ai` 7.0.162 tarball. Claims about our plans were read in this worktree at `main` commit `720e779`, and claims about SDKs from the committed mirrors under `docs/reference/*/source/`. `help.openai.com`, `openai.com`, `help.salesforce.com` and `developer.salesforce.com` refused the fetch or rendered no text, so their claims keep a marker. Nothing was installed or run, and fetched content was read as data; one vendor page embedded instructions addressed to AI agents, which were ignored.
- **Legend:** ✅ confirmed as written (a marker dropped or a citation fixed where the row says so) · ✏️ corrected in the report (the research notes keep their original text) · ⚠️ unverified or confirmed only in part
