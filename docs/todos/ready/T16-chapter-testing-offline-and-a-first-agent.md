## Goal

Write the chapter "Testing offline, and a first complete agent" (`testing-offline-and-a-first-agent`) for Part I, whose reader is a developer who has called a model API but never built an agent. It answers one research question from the sources below, section by section, with checked listings, figures and analogies where they make a concept clearer, and ends with an exercise the reader can run offline. **Research question:** How do you test an agent without a model key, and what does one complete small agent look like?
