## Goal

Write the chapter "Agents people can watch: UIs, browsers and taking over" (`agents-people-can-watch`) for Part II, whose reader is a builder who has shipped an agent on some SDK and wants the design reasons. It answers one research question from the sources below, section by section, with checked listings, figures and an analogy for each core concept, and ends with an exercise the reader can run offline. **Research question:** How should a person see, steer and take over an agent, in a UI and in a browser, when prompt injection makes the network and the credential the boundary?
