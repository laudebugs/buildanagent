# Fact-check: the Cloudflare Agents context-memory example

This log checks the claims that `verify/cloudflare-agents/examples/11-context-memory.ts`, its header comment and its README section make on 2026-11-22 (todo T44), against the pinned `agents` 0.33.0 (`dist/context/index.d.ts` and `index.js`), the mirrored docs at tag `agents@0.33.0` and the run itself.

Legend: ✅ confirmed · ✏️ corrected while drafting · ⚠️ unverified or our own inference.
