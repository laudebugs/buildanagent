# Fact-check: the book plan

This log checks the factual claims in [build-book.md](../build-book.md), ADRs [0052](../../decisions/0052-book-in-apps-on-cloudflare.md), [0053](../../decisions/0053-book-stack-and-deploy.md) and [0054](../../decisions/0054-reuse-garment-textbook-code.md), todos T1–T48 and U18–U21, and the code and docs that T1–T4 added. Claims were checked on 2026-11-19 against four kinds of source. Repo claims were read at `main` `eddc212` in the first passes and at `ea70a57` from the sixth pass on. Package claims come from `npm view <package> time`, `engines`, `peerDependencies` and the packed `.d.ts`. Cloudflare claims come from developers.cloudflare.com, read through Cloudflare's documentation search. Garment textbook claims come from `tajistudios/garment-engineering-textbook` at commit `bca44b0`, read with `gh api`. Design choices that are our own proposals are not facts and have no row. Rows follow the numbers the plan cites, so some ranges hold related claims in order.
