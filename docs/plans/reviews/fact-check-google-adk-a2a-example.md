# Fact-check: the Google ADK A2A delegation example

This log checks the claims that `verify/google-adk/examples/09-a2a-delegation.ts`, its header comment and its README text make on 2026-11-22 (todo T45), against the pinned `@google/adk` 2.5.0, `@a2a-js/sdk` 0.3.14 and the run itself. Paths below start at `verify/google-adk/node_modules/@google/adk/` (`adk`) or at the `@a2a-js/sdk` package directory (`sdk`).

Legend: ✅ confirmed · ✏️ corrected while drafting · ⚠️ unverified or our own inference.
