Agent toolkit · alpha

An agent is three layers and a loop. Read all of them.

Buildanagent splits an agent into a gateway, a loop and a harness. Each is a small TypeScript package with its own docs and its own chapter in the manual.

Read the docsOpen the manual
Figure 1. The three layers on the left, and one turn of the loop on the right.
Gateway
Calls any model the same way

The gateway streams replies, retries failures, caches prompts and records what each call costs.

Loop
Runs turns you can follow

The loop calls the model, runs its tools and stops on a condition you set.

Harness
Asks before it acts

The harness runs tools and sessions. Risky writes need a signed approval, and a cost cap ends a run that spends too much.

Six packages, one job each

@buildanagent/gatewayCalls the models.
@buildanagent/sdkRuns the loop.
@buildanagent/harnessRuns tools and sessions.
@buildanagent/agent-safetyChecks approvals and caps cost.
@buildanagent/protocolDefines the events front ends read.
@buildanagent/cliRuns agents from the terminal.
Alpha releases ship on npm under the alpha tag.Source is on GitHub.
