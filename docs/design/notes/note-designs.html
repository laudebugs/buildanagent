Two note designs to approve

Today, "Add note" opens a dialog titled "Your notes on this chapter", with a storage warning, an Export button and the note field. The notes list shows four text buttons and four colour buttons on every note. These options fix both. Each one is drawn on the manual's own page style, and the colour of the highlight you are writing changes with the dots.

1. Writing a new note

Only the note itself: the passage, the colour you can change, the field and Save. No chapter title, no export, no list. The chapter's notes open only from the Notes button.

A1 · A popover at the passage

It opens right under the words you selected, so the highlight and the note stay together. Colour dots on top, Esc cancels. The same shape as the phone sheet.

2. The list of notes

Opened by the Notes button. The goal: one visible action per note at most, with Export in the header and the storage warning as a quiet footer line.

B1 · Cards with one menu

Click a note to go to its passage. A "more" button holds Edit, Share, Colour and Delete, so each note shows one button. Export is an icon in the header.
