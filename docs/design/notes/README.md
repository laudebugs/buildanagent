# Note editor and notes list: approved designs

The owner approved these on 2026-11-23 from `note-designs.html` (open it in a browser):

- **Writing a new note: A1, a popover at the passage.** Pressing "Add note" opens a popover under the selected words, with the four colour dots on top (changing one recolours the highlight), the quoted passage, the note field, and Save note and Cancel. It has no "Your notes on this chapter" title, no storage warning, no Export button and no list.
- **The list of notes: B1, cards with one menu.** The Notes button opens a panel with a header (title and count, an Export icon button, Close), a hint line, one card per note (colour bar, quoted passage, note text, one "more" button) and a footer line ("Saved in this browser only."). The menu on a card holds Edit, Share, Colour (four dots) and Delete.

The B2, B3, A2 and A3 mocks were not chosen. The phone sheet keeps its own layout.
