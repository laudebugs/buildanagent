# Sticky header and reading settings: approved designs

The owner approved these on 2026-11-23 from `reading-designs.html` (open it in a browser):

- **Sticky header: H2.** On a phone the header is one slim row (52 px: wordmark, search, the settings button, theme, a menu button holding Contents, Glossary, Sources and Notes). It slides away when the reader scrolls down and returns on the first upward scroll. On desktop it stays visible (56 px). A thin progress line along the header fills as the reader moves down the chapter, and it stays at the very top of the screen while the header is hidden.
- **Reading settings: S1.** A settings button in the header opens a panel under it (a bottom sheet on phones) with a list of typeface pairings (each with a sample), a five-step text size bar (90, 100, 115, 130, 150%) and a Reset link. The choice is saved on the device and applies to every chapter.

`font-choices.html` shows the icon options for the settings button and eight candidate pairings. The owner's picks are pending; the header can be built first, with the settings button added when the settings ship.

## Final choices (2026-11-23)

- **Icon: I1**, a big A and a small a on one baseline, centred in the button.
- **Pairings (four):**
  1. **Book** (default): Instrument Serif headings, Literata body.
  2. **Readable**: Atkinson Hyperlegible for headings and body.
  3. **Sans 6**: Space Grotesk headings, Inter body.
  4. **Slab (Bitter)**: Bitter for headings and body.
- `more-fonts.html` shows the second set of candidates. The code font (Manual Code) stays the same in every pairing.
