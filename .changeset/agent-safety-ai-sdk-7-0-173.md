The AI SDK adapters are now tested against `ai` 7.0.173, `@ai-sdk/anthropic` 4.0.105, `@ai-sdk/openai` 4.0.118 and `@ai-sdk/provider-utils` 5.0.81. The optional peers name exactly those releases, so a project on any other release, such as `ai` 7.0.162, now gets a peer warning.
