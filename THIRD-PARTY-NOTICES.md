# Third-party notices: nine mirrored doc sets and one vendored skill keep their upstream licences, the book credits the garment engineering textbook, and its fonts keep the OFL

This repository contains upstream documentation that other projects wrote. Our own code and docs are licensed as [LICENSE](LICENSE) describes, but that licence does not cover the mirrors under `docs/reference/*/source/`. Each mirror is an unmodified copy of upstream files at a recorded tag or commit, and each keeps its upstream licence file beside it. If you reuse a mirrored file, follow the licence in its row below. The book also adapts code from the owner's garment engineering textbook, and those files carry Apache-2.0 alone instead of our usual choice of two licences. The book serves seven font families under the SIL Open Font License 1.1, and its isometric figures use a vendored copy of the MIT-licensed anatomy skill.

## The anatomy skill is vendored at one upstream commit, under its MIT licence

[`.agents/skills/anatomy/`](.agents/skills/anatomy/) is a copy of [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) at commit `1482e8469b0a9e0d8cc18ea2740a01423d29ae80` (2026-10-18), fetched as that commit's tarball on 2026-11-19. The owner approved vendoring it on 2026-11-19. Its licence is MIT, copyright 2026 Ryan, and its unchanged [LICENSE](.agents/skills/anatomy/LICENSE) sits beside the files; the repository has no NOTICE file at that commit, so none is copied. Every copied file is byte-identical to the tarball's, `SKILL.md` and the kit, audit and line check included. Four kinds of upstream file are left out:

- the built example pages (`examples/**/*.html`), which each example's `build.mjs` writes again;
- the printed sheets (`examples/**/*.pdf`), which `scripts/print.mjs` writes again;
- the `.github/` folder: the upstream CI, issue templates and README images;
- the files that publish a figure to the skill's community gallery, by the owner's decision of 2026-11-19: `scripts/publish.mjs` and its test, `scripts/session.mjs` and its test, which read an agent's session logs to time a figure for the gallery, `scripts/fingerprint.mjs`, which only `publish.mjs` uses, and `references/publish.md`.

Because the copy is unchanged, some of its docs name files that are not in it. `README.md` shows five images from `.github/assets/`, `CONTRIBUTING.md` links `.github/workflows/ci.yml`, and `SKILL.md`, `README.md` and `CHANGELOG.md` mention publishing and the built example pages. Each example's page comes back when its `build.mjs` runs. The repository has no link checker of its own; a link check over the repository should skip `.agents/skills/anatomy/`. To update the copy, fetch the new commit's tarball, diff it against this folder with the same four exclusions, and change the commit here.

The book uses the kit (`kit/iso-kit.mjs`, `kit/audit.mjs`, `kit/iso.css`) and the line check (`scripts/lines.mjs`, which runs `scripts/drive.mjs` in headless Chrome) from this folder; [`apps/manual/README.md`](apps/manual/README.md) says how. Nothing in the book's own docs copies the skill's text or its agent instructions.

## The book's seven fonts are subsets of OFL fonts from google/fonts

The book in `apps/manual/` serves its own fonts, so a reader's browser fetches nothing from Google. Each family comes from the [google/fonts](https://github.com/google/fonts) repository at commit `9bbbcda6f8aa91198223c77345d548af4b61940d` (2026-11-11), and [`apps/manual/fonts/sources.json`](apps/manual/fonts/sources.json) records the SHA-256 of every upstream file. The served files are WOFF2 subsets that keep Latin, punctuation, arrows, maths and box-drawing characters. A subset is a Modified Version under the SIL Open Font License 1.1, so each stays under that licence, and each family's unchanged `OFL.txt` ships beside its files. [`apps/manual/scripts/subset-fonts.py`](apps/manual/scripts/subset-fonts.py) writes the subsets with fontTools 4.68.0, from the family list in the same `sources.json`.

Only Bitter's licence names a Reserved Font Name, and the next paragraphs say why each family keeps or changes its name. Google Sans Code's `TRADEMARKS.md` adds one rule that matters here: "Google", "Google Sans" and "Google Sans Code" are trademarks of Google LLC, and the "Google Sans Code" mark may be used only in connection with the original font software. The book's files are derived from Google Sans Code, not the original, so they carry the neutral family name "Manual Code" in their file names, their CSS and their name tables. The subsetting script also drops the records that name Google as the manufacturer and vendor, and keeps the copyright, trademark notice, designer and licence records. Nothing in the book implies that Google made or endorses these files.

Instrument Serif and Literata keep their names. Neither licence reserves a font name, and neither folder in google/fonts carries a `TRADEMARKS.md`. Literata's name table includes the notice "Literata is a trademark of Google Inc.", which the subsets keep unchanged. The owner chose to keep the Literata name on 2026-11-19.

The four families of the reading settings, Atkinson Hyperlegible, Space Grotesk, Inter and Bitter, keep their names too. None of their folders in google/fonts carries a `TRADEMARKS.md`. Bitter's licence reserves the name "Bitter Pro", which the OFL bars a modified version from using. The book serves the family as Bitter, so it does not use the reserved name. "BitterPro" survives in the subsets only in the copyright notice's URL, `https://github.com/solmatas/BitterPro`, which the OFL requires them to keep. A test checks that no other name record names Bitter Pro. As Literata's do, two name tables carry a trademark notice, which the subsets keep unchanged: "Inter UI and Inter is a trademark of rsms." and "Bitter is a trademark of Sol Matas (www.solmatas.com)." Neither family's licence reserves that name, so the book keeps the names Inter and Bitter as it kept Literata's; as of 2026-11-23 the owner has not ruled on these two.

The docs site serves the same files. [`apps/docs/public/fonts/`](apps/docs/public/fonts/) is a byte-for-byte copy of the book's Instrument Serif, Inter and Manual Code folders, licence files and `TRADEMARKS.md` included, which `pnpm --filter @buildanagent/docs tokens` writes and a docs test checks. The docs set their body text in Inter, so they do not carry Literata. Everything above about Instrument Serif, Inter and Manual Code applies to that copy unchanged, including Inter's trademark notice and, as of 2026-11-23, the owner's open question about the name.

## Quotations elsewhere are short, attributed excerpts

Two kinds of third-party text appear outside the mirrors, both as short quotations with attribution. First, the practitioner research in [`docs/research/practitioners/`](docs/research/practitioners/) quotes Hacker News comments, each credited to its author with a link to the comment. These quotations remain the work of their authors.

## The Claude Agent SDK docs are not distributed

Anthropic's Claude Agent SDK docs are not openly licensed, so this repository leaves them out. Their mirror path, `docs/reference/claude-agent-sdk/source/`, is gitignored, and anyone who needs a local copy regenerates it with `pnpm run fetch-docs` in `verify/claude-agent-sdk/` ([reference README](docs/reference/claude-agent-sdk/README.md#regenerate-the-mirror-and-re-verify)).
